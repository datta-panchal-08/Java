Welcome to my **Java Backend Development** repository!

## 📚 Topics Covered

### 1. Core Java

- Java fundamentals and syntax
- Classes and objects
- Object-Oriented Programming (OOP)
- Constructors and methods
- Exception handling
- Collections Framework
- Multithreading fundamentals
- Practical coding exercises

### 2. JDBC — Java Database Connectivity

- JDBC architecture and workflow
- Database connections
- SQL execution from Java
- CRUD operations
- PreparedStatement and ResultSet
- Database configuration and connection handling

**Projects:**
- Garage Management System
- Student Management System

### 3. Java Servlets

- Servlet lifecycle
- HttpServlet
- Handling HTTP requests and responses
- ServletConfig and ServletContext
- Cookies and HTTP sessions
- Form handling and login workflow
- Servlet application deployment using Tomcat

### 4. Spring Core

- Inversion of Control (IoC)
- Dependency Injection (DI)
- Spring Beans and IoC Container
- BeanFactory vs ApplicationContext
- XML-based configuration
- Constructor, setter and field injection
- Autowiring: byName, byType and constructor
- Bean scopes
- Bean lifecycle and lifecycle callbacks

### 5. Spring Boot

- Spring Boot project setup with Maven
- Application configuration
- REST API development
- `@RestController` and `@RequestMapping`
- HTTP methods and request mappings
- Dependency Injection in Spring Boot
- CRUD operations
- Connecting applications with MySQL

**Projects:**

**BookAPI**
- Built a basic REST API for book management.
- Implemented endpoints to work with book data.
- Practiced request mapping and REST controller fundamentals.

**Student Management API**
- Implemented student-related CRUD operations.
- Practiced REST endpoints and application structure.

### 6. Spring Data JPA & Hibernate

- Entity mapping using `@Entity` and `@Id`
- Primary key generation using `@GeneratedValue`
- Repository interfaces
- Database operations using `JpaRepository`
- CRUD operations with MySQL
- Updating entity data
- Understanding foreign keys and database relationships
- JSON serialization of related entities

**Entity Relationships**

| Annotation | Concept |
|---|---|
| `@OneToOne` | One entity relates to one entity |
| `@OneToMany` | One entity relates to multiple entities |
| `@ManyToOne` | Multiple entities relate to one entity |
| `@ManyToMany` | Multiple entities relate to multiple entities |
| `@JoinColumn` | Configures a relationship's join column |
| `mappedBy` | Identifies the inverse side of a bidirectional relationship |

Also exploring fetch types such as `LAZY` and `EAGER`, cascading operations, and relationship handling in REST APIs.
